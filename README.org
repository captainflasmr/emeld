#+TITLE: Emeld: Meld-Inspired Local Diff
#+AUTHOR: Antigravity

* Introduction
Emeld is a simple, side-by-side directory comparison tool for Emacs. It is designed to be a lightweight and maintainable alternative to other directory diff tools, with a focus on ease of use and a clean hierarchy.

* Features
- Side-by-side view in a single buffer.
- Recursive glob-based filtering (like Meld).
- Instant toggles for New, Modified, and Identical files.
- Tree folding (~TAB~).
- File copying between directories (~C~).
- Export changes as a unified-diff patch (~P~).
- Side-aware navigation (~n~/~p~) and side-jumping (~o~).
- Integration with ~ediff~.
- Fully themeable (uses standard Emacs faces).

* Installation
Copy the files to your load path and add the following to your init file:
#+begin_src elisp
(add-to-list 'load-path "~/.emacs.d/offline-packages/local-packages/emeld")
(require 'emeld)
#+end_src

* Usage
Run ~M-x emeld-diff~ and select the two directories you wish to compare.
Alternatively, run ~M-x emeld-diff-dwim~ to automatically use open Dired buffers as the comparison sources.

* Transient Menu (~?~)

The transient menu is organized into four groups:

- ~View~ :: Toggle file visibility (~s~ same, ~m~ modified, ~a~ added, ~F~ filtered, ~T~ tree-lines), indent (~>~/~<~).
- ~Navigate~ :: Scan (~g~ simple, ~G~ full diff) and jump (~o~ other side, ~M-n~/~M-p~ next/prev change).
- ~File~ :: Operate on files (~RET~ ediff/open, ~SPC~ soft diff/fold, ~C~ copy, ~d~ delete, ~w~ copy path, ~P~ format patch).
- ~Filename~ :: Toggle filter groups on/off (~[x]~/~[ ]~ checkmarks), ~l~ list all globs.

* Key Bindings
| Key       | Action                                 |
|-----------+----------------------------------------|
| ?         | Transient menu                         |
| TAB       | Toggle expansion of a directory        |
| RET, e, = | Action (Ediff if different)            |
| f, v      | Find File (Open current side)          |
| d         | Delete file/dir from current side      |
| C         | Copy to the other side                 |
| P         | Format as patch (unified diff)         |
| w         | Copy filename (C-u w for full path)    |
| SPC       | Fold/Unfold (Dir) or Soft Diff (File)  |
| o         | Jump to the other side                 |
| h         | Toggle hidden files                    |
| F         | Toggle filtered (glob) files           |
| s         | Toggle same (identical) files          |
| m         | Toggle modified files                  |
| a         | Toggle added (new) files               |
| g         | Rescan (uses ~emeld-simple-comparison~) |
| G         | Force full content-diff scan           |
| n/p       | Navigation (Side-aware)                |
| M-n/M-p   | Jump to next/previous file change      |
| C-c f     | Toggle a named filter group on/off     |

* Customization

- ~emeld-filter-groups~: Named groups of globs toggleable with ~C-c f~.  Defaults:

  | Group           | Globs                                                                                                       |
  |-----------------+-------------------------------------------------------------------------------------------------------------|
  | Backups         | ~#*#~, ~.#*~, ~~*~, ~*~~, ~*.orig~, ~*.bak~, ~*.swp~                                                        |
  | OS metadata     | ~.DS_Store~, ~._*~, ~.Spotlight-V100~, ~.Trashes~, ~Thumbs.db~, ~Desktop.ini~                               |
  | Version Control | ~.git~, ~.svn~, ~.hg~, ~CVS~, ~_darcs~, ~.bzr~, ~_MTN~, ~.fslckout~, ~_FOSSIL_~, ~.fos~, ~.osc~             |
  | Binaries        | ~*.pyc~, ~*.a~, ~*.obj~, ~*.o~, ~*.so~, ~*.la~, ~*.lib~, ~*.dll~, ~*.exe~                                   |
  | Media           | ~*.jpg~, ~*.gif~, ~*.png~, ~*.bmp~, ~*.wav~, ~*.mp3~, ~*.ogg~, ~*.flac~, ~*.avi~, ~*.mpg~, ~*.xcf~, ~*.xpm~ |

- ~emeld-show-same~: Whether to show identical files (default nil).
- ~emeld-simple-comparison~: Set to t for fast size-only matching.
- ~emeld-dir-prefix~: Unicode prefix for directory names (default ~"📁 "~).

* Per-Project Configuration with ~.dir-locals.el~

Emeld ships with Meld-style default filter groups (see above).  To override them per
project, place a ~.dir-locals.el~ file above the left directory:

#+begin_src elisp
;;; .dir-locals.el
((nil
  . ((emeld-filter-groups . (("Backups" t "*~" "*.bak" "*.orig")
                            ("Hidden" nil ".*")
                            ("Logs" t "*.log" "logs/*")
                            ("Config" nil "*.cfg" "config/*"))))))
#+end_src

Toggle named groups on/off from the transient menu (~?~ then ~f~) or directly with ~C-c f~.
The header line shows the current display state and active groups in brackets.
