#+TITLE: Mild: Meld-Inspired Local Diff
#+AUTHOR: Antigravity

* Introduction
Mild is a simple, side-by-side directory comparison tool for Emacs. It is designed to be a lightweight and maintainable alternative to other directory diff tools, with a focus on ease of use and a clean hierarchy.

* Features
- Side-by-side view in a single buffer.
- Recursive glob-based filtering (like Meld).
- Instant toggles for New, Modified, and Identical files.
- Tree folding (~TAB~).
- File copying between directories (~C~).
- Side-aware navigation (~n~/~p~) and side-jumping (~o~).
- Integration with ~ediff~.
- Fully themeable (uses standard Emacs faces).

* Installation
Copy the files to your load path and add the following to your init file:
#+begin_src elisp
(add-to-list 'load-path "~/.emacs.d/offline-packages/local-packages/mild")
(require 'mild)
#+end_src

* Usage
Run ~M-x mild-diff~ and select the two directories you wish to compare.
Alternatively, run ~M-x mild-diff-dwim~ to automatically use open Dired buffers as the comparison sources.

* Key Bindings
| Key       | Action                              |
|-----------+-------------------------------------|
| TAB       | Toggle expansion of a directory     |
| RET, e, = | Action (Ediff if different)         |
| f, v      | Find File (Open current side)       |
| d         | Delete file/dir from current side   |
| C         | Copy to the other side              |
| w         | Copy filename (C-u w for full path) |
| SPC       | Fold/Unfold (Dir) or Soft Diff (File)|
| o         | Jump to the other side              |
| h         | Toggle hidden files                 |
| F         | Toggle filtered (glob) files        |
| s         | Toggle same (identical) files       |
| m         | Toggle modified files               |
| a         | Toggle added (new) files            |
| g         | Full rescan/refresh                 |
| n/p       | Navigation (Side-aware)             |
| M-n/M-p   | Jump to next/previous file change   |

* Customization
- ~mild-filter-globs~: List of globs to ignore (e.g., ~".git"~, ~"*.elc"~).
- ~mild-show-hidden~: Whether to show dotfiles.
- ~mild-show-same~: Whether to show identical files (default nil).
- ~mild-simple-comparison~: Set to t for fast size-only matching.
