#+TITLE: Changelog for Emeld

* [0.13.0] - 2026-05-24
** Added
- Incremental same-scan: toggling ~S~ now runs ~diff -rqs~ in the background and merges identical files into the existing tree without blanking the screen or losing context (point position, expanded folders, marks preserved).
** Changed
- Keybinding reorganization: Same toggled with ~S~, Modified with ~M~, New/Added with ~N~, Strikethrough with ~s~.
- Display state indicators updated to match new keys (header line shows ~[S]~, ~[M]~, ~[N]~, ~[s]~).
- Transient menu labels shortened: ~Same~→~S~, ~New~→~N~, ~Modified~→~M~.
- Wrapped ~file-name-nondirectory~ calls with ~directory-file-name~ to fix blank directory names when showing identical files.

* [0.12.0] - 2026-05-23
** Added
- Confirmation prompt when toggling show-same (~s~): warns about potential freeze and asks to proceed when no cached data.
- Point position preserved across async refresh cycle (point returns to the same file after copy, rescan, etc.).
** Changed
- Marks now cleared after bulk copy completes.
** Fixed
- ~emeld--move-to-node-name~ regex fixed to include ~*~ in the skip character class (nav was stuck on mark column).

* [0.11.0] - 2026-05-23
** Added
- Strikethrough display for orphan files on the missing side (Meld-style).  When a file exists only on one side, the other side shows the tree path and filename with ~:strike-through~.  Toggle with ~S~.
- ~emeld-show-strikethrough~ defcustom for controlling strikethrough display (default ~t~).
- Dired-style marking system: ~m~ to mark, ~u~ to unmark, ~U~ to unmark all.  When marks exist, ~C~ copies all marked nodes to the other side.
** Changed
- Keybinding reorganization: ~m~ and ~u~/~U~ now handle marking (was ~emeld-toggle-show-different~); ~emeld-toggle-show-different~ moved to ~M-m~.

* [0.10.0] - 2026-05-23
** Added
- ~diff -rqs~ mode for showing identical files (toggle ~s~).  First scan fetches and caches; subsequent toggles are instant re-renders.
- ~emeld-dynamic-suffix~ transient suffix class for live ~[x]~/~[ ]~ updates on filter group toggles.
- Tree expansion state preserved across rescans (collapsed directories stay collapsed).
- GC and performance optimizations in diff sentinel for large trees (10,000+ files).
- ~emeld-simple-comparison~ kept as obsolete alias for ~.dir-locals.el~ compatibility.
** Removed
- ~fd~ dependency entirely (was causing performance and compatibility issues).  All scanning is now ~diff -rq~ only.
- ~emeld-simple-comparison~ defcustom (no more size-only vs content mode).
- ~emeld-refresh-full~ and ~G~ keybinding (no separate full-scan mode).
- ~emeld-show-filtered~ toggle, ~F~ keybinding, and ~emeld-filtered-face~ (filter groups controlled entirely via ~ca~–~cz~ in the transient).
** Changed
- Filter groups now passed as ~--exclude~ patterns to ~diff~, so filtering happens at the scan level (like Meld).
- ~diff -rq~ no longer has hard-coded ~--exclude=.git~; the Version Control filter group (which includes ~.git~) controls it.
- Transient menu reorganized into ~File Status~ (~s~ same, ~m~ modified, ~a~ added) and ~View~ (~T~ tree-lines, indent, pane resize) groups.
- ~emeld--entries-to-nodes~ simplified (removed filtered-file status override).
- ~g~ now always does a single scan (no simple/full distinction).

* [0.9.2] - 2026-05-21
** Added
- ~emeld-column-ratio~ customizable left-pane width percentage (default 50).
- ~{~/~}~ bindings and transient entries to shrink/grow the left column by 5%.

* [0.9.1] - 2026-05-21
** Changed
- Transient menu restructured into ~View~, ~Navigate~, ~File~, and ~Filename~ groups.
- Toggle indicators use ~[x]~/~[ ]~ instead of ~✓~ for consistent alignment.

* [0.9.0] - 2026-05-21
** Added
- ~emeld-format-patch~ (~P~): export all changed files as a unified-diff patch (left→right direction).

* [0.8.0] - 2026-05-20
** Added
- ~emeld-list-filter-groups~ (~l~ in the transient Filename column): opens a buffer listing every filter group with all its globs and active state.
- Transient Filename column shows glob count per group (e.g. ~✓ Backups (7)~).
** Changed
- Header line ~f~ indicator renamed to ~F~ to match the keybinding.
- Inline glob display removed from transient (moved to dedicated buffer).

* [0.7.0] - 2026-05-20
** Added
- ~emeld-filter-groups~ entries now support an optional boolean (~t~/~nil~) after the name to set the default active state.  All five default groups active by default.
- Transient menu reorganized: "File status" column (Same/Modified/Added) as first, "Filename" with per-group suffix entries, "Toggles" (filtered/tree-lines).
** Changed
- ~emeld-filter-globs~ removed; all filtering now exclusively through ~emeld-filter-groups~.
- ~emeld-show-hidden~ and hidden-files toggle removed; dotfiles now filtered via filter groups only.
- Header line simplified: no legend swatches, scan mode shown as bold/shadow ~FAST~/~NORMAL~ toggles.
- Navigation column (~n~/~p~) removed from transient; ~M-n~/~M-p~ kept in Actions.
- Scan mode labels renamed from ~SIMPLE~/~FULL~ to ~FAST~/~NORMAL~.

* [0.6.0] - 2026-05-20
** Added
- Transient menu (~?~ key) with Toggles, Actions, Navigation, Indent, and Filter Groups columns in a single row.
** Changed
- Filter groups in transient via completion prompt with active-count header (avoids ~:setup-children~ compatibility issues).
- ~emeld--apply-dir-locals~ reads ~.dir-locals.el~ directly via ~locate-dominating-file~.
** Fixed
- ~emeld--move-to-node-name~: ~let~→~let*~ for dependent bindings.

* [0.5.0] - 2026-05-20
** Added
- Transient menu (~?~) with Toggles, Actions, Navigation, and Indent sections in a single row.
- `emeld-dispatch` transient prefix with `:transient t` on navigation and toggle commands.
** Changed
- `emeld--apply-dir-locals` now reads `.dir-locals.el` directly using `locate-dominating-file`.

* [0.4.0] - 2026-05-20
** Added
- ~emeld-filter-groups~: named groups of globs toggleable with ~C-c f~. Active groups shown in brackets in the header line.
- ~.dir-locals.el~ documentation for per-project filter configuration.
** Changed
- ~emeld--filtered-p~ now also checks active filter groups.
- Header line shows active group names (e.g. ~[build] [logs]~).
** Added
- ~emeld-dir-face~ for directory names (font-lock-type-face + bold), distinct from file diff-status faces.

* [0.3.0] - 2026-05-20
** Changed
- ~emeld-action~ is now side-aware: ~RET~ on the right column opens the right-side path.
- ~emeld-show-tree-lines~ now defaults to ~t~.
- Header line shows ~[SIMPLE]~ or ~[FULL]~ scan mode indicator.
** Added
- ~G~ to force a full content-based scan (ignores ~emeld-simple-comparison~).
- ~emeld-dir-prefix~ (default ~"📁 "~) for a configurable directory icon; directory names rendered in bold.
- ~emeld-refresh-full~ bound to ~G~.
** Fixed
- Bug in ~emeld--move-to-node-name~: used ~let~ instead of ~let*~ for dependent bindings, causing void-variable errors (~has-left~, ~has-right~).

* [0.2.1] - 2026-05-20
** Added
- Root directories now rendered as collapsible tree nodes at the top (different names on left/right columns via new ~name-right~ slot).  ~RET~ on the root prompts to change the directory for the current side.
- ~M-n~/~M-p~ for next/previous change navigation (file-only), ~emeld-next-change~ / ~emeld-previous-change~.
- ~d~ to delete the file/directory at point from the current side, ~emeld-delete~.

* [0.2.0] - 2026-05-20
** Added
- Initial implementation of `emeld.el` side-by-side comparison.
- Content-based comparison using ~diff -q~ for high accuracy.
- Performance option ~emeld-simple-comparison~ for size-only matching.
- Recursive glob matching for filtering (matches filenames or relative paths).
- Toggles for hidden and filtered files.
- New visibility toggles for **Same** (~s~), **Modified** (~m~), and **Added/New** (~a~) files.
- Directory folding and unfolding (~TAB~).
- Added asynchronous directory scanning (~make-thread~) to prevent UI hangs.
- Added contextual ~SPC~ behavior: Toggle expansion for directories or show Soft Diff for files.
- Added ~emeld-indent-offset~ to customize tree indentation depth.
- Added ~emeld-diff-dwim~ with robust directory detection and collision safety.
- Added ~emeld-simple-comparison~ option for fast, size-only matching.
- Added side-aware navigation (~n~/~p~) that remembers left/right column focus.
- Added side-jumping navigation (~o~) to switch between columns.
- Added ~w~ to copy filename at point (~C-u w~ for full path).
- REALIGNMENT: Glob filter toggle moved to ~F~.
- Standard file actions: ~RET~, ~e~, ~=~ for Ediff; ~f~, ~v~ for Find File.
- Full theming support (inherits from standard Emacs ~diff-*~ faces).
- Confirmation messages in the echo area for all UI toggles.
- Compatibility fixes for older Emacs versions (27.1+).
