#+TITLE: Changelog for Emeld

* [0.16.0] - 2026-05-25
** Added
- Presets: ~emeld-save-preset~ / ~emeld-load-preset~ / ~emeld-delete-preset~ (transient ~ps~/~pl~/~pd~) save and recall a directory pair via completion.  Stored in ~emeld-presets~ and persisted across sessions through ~savehist~.
- Per-stage benchmark report for the identical-files (~S~) merge, separate from the initial scan.
- ~emeld-benchmark-record~ appends timing runs — stamped with machine specs and the emeld git revision — to an Org log (~emeld-benchmark-file~, default ~BENCHMARKS.org~); ~emeld-benchmark-system-info~ inserts the specs at point.  ~test/bench.sh~ feeds the same log (~EMELD_BENCH_RECORD~/~SAME~/~FILE~ env vars).
- Identical-files scan shows a live entry count while scanning, like the initial scan.
** Changed
- Header-line scan counters update continuously during a scan, not only on point movement.
- Benchmark report writes ~cumulative~ instead of ~cum~.
** Removed
- Default ~C-c~ keybindings (~C-c f~, ~C-c s~, ~C-c l~) — use the transient or bind them yourself.
- The "Finished loading identical files." message (the ~[Ready]~ header state suffices).

* [0.15.0] - 2026-05-25
** Added
- ~.gitignore~ support, on by default (~emeld-respect-gitignore~), toggled with ~G~.  Honors nested ~.gitignore~, ~.git/info/exclude~ and the global excludes file.
- Live header-line scan progress: an entry tally while ~diff~ runs and a progress bar while the tree builds.
** Changed
- ~emeld-respect-gitignore~ is buffer-local.
- Identical-files merge is near-linear on large trees (O(1) hash index instead of quadratic sibling scans).
- Intermediate redraws throttled via ~emeld-render-throttle~ (default 0.15s).
** Fixed
- Gitignore uses one cached, async-prewarmed ~git ls-files~ query per root instead of per-file ~git check-ignore~ — fixes UI freezes/hangs on large repos.
- Cached ignore set dropped on rescan, so ~.gitignore~ edits take effect on ~g~.

* [0.14.0] - 2026-05-25
** Added
- Org-style visibility cycling: ~S-TAB~ cycles the whole tree (TOP → DIRS → CHANGES), ~TAB~ the subtree at point.
- ~[~ collapse all, ~]~ expand all, ~\\~ expand only paths to changes (transient ~View~ group).
** Changed
- Single-sided directories populated and expanded eagerly on the initial scan.
- ~TAB~ rebound to ~emeld-cycle-subtree~ (old ~emeld-toggle-expand~ still defined).
** Fixed
- Deeply nested subtrees no longer go missing after the initial scan.
- Expanding a single-sided directory no longer duplicates its path chain.

* [0.13.0] - 2026-05-24
** Added
- Incremental same-scan: toggling ~S~ merges identical files into the existing tree without losing point, expansion, or marks.
** Changed
- Keys: Same ~S~, Modified ~M~, New ~N~, Strikethrough ~s~ (header indicators and transient labels updated to match).
- Tree sorted once at completion instead of per-chunk; responsiveness tuning for large directories.

* [0.12.0] - 2026-05-23
** Added
- Confirmation prompt before showing identical files when uncached.
- Point preserved across async refreshes.
** Changed
- Marks cleared after bulk copy.
** Fixed
- Navigation no longer sticks on the mark column.

* [0.11.0] - 2026-05-23
** Added
- Strikethrough display for orphan files on the missing side (~emeld-show-strikethrough~, default ~t~).
- Dired-style marking (~m~/~u~/~U~); ~C~ copies all marked nodes.
** Changed
- ~m~/~u~/~U~ now mark; ~emeld-toggle-show-different~ moved to ~M-m~.

* [0.10.0] - 2026-05-23
** Added
- ~diff -rqs~ mode for showing identical files (~s~), cached after first scan.
- Tree expansion state preserved across rescans.
** Changed
- Filter groups passed as ~--exclude~ to ~diff~ (filtering at the scan level); ~.git~ controlled by the Version Control group.
** Removed
- The ~fd~ dependency; all scanning is ~diff -rq~.
- ~emeld-simple-comparison~, ~emeld-refresh-full~/~G~, and the ~emeld-show-filtered~/~F~ toggle.

* [0.9.2] - 2026-05-21
** Added
- ~emeld-column-ratio~ (default 50) and ~{~/~}~ to shrink/grow the left column.

* [0.9.1] - 2026-05-21
** Changed
- Transient restructured into ~View~/~Navigate~/~File~/~Filename~ groups; toggle indicators use ~[x]~/~[ ]~.

* [0.9.0] - 2026-05-21
** Added
- ~emeld-format-patch~ (~P~): export changed files as a unified-diff patch (left→right).

* [0.8.0] - 2026-05-20
** Added
- ~emeld-list-filter-groups~ (transient ~l~): a buffer listing every filter group, its globs and active state.

* [0.7.0] - 2026-05-20
** Added
- ~emeld-filter-groups~ entries accept an optional ~t~/~nil~ default-active flag.
** Changed
- Removed ~emeld-filter-globs~ and ~emeld-show-hidden~; all filtering is via ~emeld-filter-groups~.

* [0.6.0] - 2026-05-20
** Added
- Transient menu (~?~) with toggle, action, navigation and filter-group columns.

* [0.5.0] - 2026-05-20
** Added
- ~emeld-dispatch~ transient prefix, with ~:transient t~ on navigation/toggle commands.
** Changed
- ~emeld--apply-dir-locals~ reads ~.dir-locals.el~ via ~locate-dominating-file~.

* [0.4.0] - 2026-05-20
** Added
- ~emeld-filter-groups~: named glob groups, active groups shown in the header line; ~.dir-locals.el~ support for per-project config.
- ~emeld-dir-face~ for directory names.

* [0.3.0] - 2026-05-20
** Added
- ~emeld-dir-prefix~ (default ~"📁 "~) for a configurable directory icon.
** Changed
- ~emeld-action~ is side-aware (~RET~ on the right column opens the right path); ~emeld-show-tree-lines~ defaults to ~t~.

* [0.2.1] - 2026-05-20
** Added
- Collapsible root nodes (per-side names); ~RET~ on the root changes that side's directory.
- ~M-n~/~M-p~ next/previous change; ~d~ deletes the entry at point from the current side.

* [0.2.0] - 2026-05-20
** Added
- Initial implementation: side-by-side comparison via ~diff -q~, recursive glob filtering, visibility toggles for Same/Modified/Added, directory folding (~TAB~), contextual ~SPC~, Ediff integration (~RET~/~e~/~=~), find-file (~f~/~v~), side-aware navigation (~n~/~p~/~o~), ~w~ to copy paths, and full ~diff-*~ face theming.  Requires Emacs 27.1+.
