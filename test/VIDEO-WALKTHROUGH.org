#+TITLE: emeld Walkthrough
#+AUTHOR: James Dyer
#+OPTIONS: toc:nil num:nil
#+STARTUP: overview

Emeld is a simple, side-by-side directory comparison tool for Emacs. It is designed to be a lightweight and maintainable alternative to other directory diff tools, with a focus on ease of use and a clean hierarchy.

=?= opens the transient menu; =q= closes it.

#+begin_src elisp :exports none
Emacs theme (load-theme 'doom-lantern t)
#+end_src

* 1. Open the comparison and lay out the tree

- =M-x emeld-diff= with =test/example/left= and =test/example/right=.
- ~TAB~ to fold layers of diffs
- ~t~ toggles tree lines.
- ~v~ ~f~ show file metadata
- ~z~ cycles density: compact → extreme → wide.
- Move the window size to see dynamic tree re-render
- move trees closer/further apart
- modify the tree indent

* 2. Statuses and display filters

- ~S~ toggles identical files.
- ~N~ toggles new files.
- ~M~ toggles modified files.

* 3. Change navigation

- ~M-n~ jumps to the next changed file.
- ~M-p~ jumps to the previous changed file.
- ~o~ to hop trees

* 4. Peek and word-level refinement

- ~TAB~ on a modified file peeks an inline diff underneath the row.
- ~TAB~ again collapses the peek.
- Watch: the changed words inside modified lines are highlighted.
- Watch: the peek expands and collapses without leaving the tree.

* 5. Change inspection through ediff/diff-mode

- ~SPC~ view diff in separate buffer
- ~e~ view difference and hunk copy where required

* 6. Hunk copy and undo

- ~TAB~ opens the inline diff.
- Point inside a hunk.
- ~a~ applies that change block to the other file.
- ~u~ undoes the last copy.

* 7. Content filters

- ~v~ opens the View menu.
- ~i~ cycles whitespace filtering: off → amount → all.
- ~L~ toggles line-ending filtering (CRLF vs LF).
- ~B~ toggles blank-line-only changes.
- ~C~ toggles case-only changes.

* 8. Filename filter groups

- ~F~ opens the Filter menu.
- Press the group key shown by the menu, for example the key for =Backups=.

* 9. .gitignore respect

- ~I~ toggles .gitignore respect off and on.
- So now the build directory is visible

* 10. Jump to file

- ~j~ opens jump-to-file completion.
- Complete a path such as =src/main.el= or =many/f10.txt=.

* 11. Narrow and widen

- ~C-x n n~ narrows to a regexp, e.g. =src/= or =\\.el\\'=.
- ~C-x n w~ widens back to the full tree.

* 12. Mark, copy, delete

- ~m~ marks =to-copy.txt= on its current side.
- ~C~ copies the marked file to the other side.
- For =to-delete.txt=, mark the struck side and press ~C~ to delete it.
- ~x~ deletes marked nodes from their marked sides.

* 13. Undo log

- ~s~ for sync menu
- ~u~ undoes the last delete, copy, or applied change block.
- ~l~ lists undoable operations, newest first.
- Press ~u~ or ~RET~ on a row to undo that entry.

* 14. Session hide

- ~C-k~ hides the node at point for the current session.
- ~C-u C-k~ restores everything.

* 15. Patch export

- Press ~P~ to format the changes as a unified patch.

* 16. Dired integration

- ~A~ opens the left side in Dired.
- ~B~ opens the right side in Dired.

* 17. Recent comparisons

- =M-x emeld-recent= reopens a previous comparison.
- Or use ~d~ → ~r~ from the transient menu.

* 18. Git revisions / history stepping

- run =M-x emeld-git-diff=.
- Compare =HEAD~1= with =[working tree]=.
- Start from =HEAD=.
- ~,~ steps older; ~.~ steps newer.
