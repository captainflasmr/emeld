#+TITLE: emeld example comparison (demo + test fixture)
#+OPTIONS: toc:2

* Generating

  #+begin_src sh
  test/make-example.sh              # → test/example/{left,right,git-repo}
  #+end_src

  The output is gitignored: the generator (=test/emeld-example.el=) is the
  source of truth.  Contents and modification times are fixed, so the
  generated trees — and videos recorded from them — are reproducible;
  regenerate before each recording.  =make-example.sh= also builds the git
  demo repository.  The generator is loaded by the test suite too, which
  turns it into a fixture for the end-to-end tests in =emeld-tests.el=.

  =test/example= is itself a throwaway git work tree.  That matters when
  the fixture lives inside the emeld repository (where =.gitignore= ignores
  =test/example/= wholesale): git work-tree discovery stops at
  =test/example/.git=, so the fixture's own =.gitignore= files — not the
  enclosing repository's rules — decide what the gitignore demos hide.

* Running the comparison

  #+begin_src sh
  emacs -Q -L . -l emeld.el --eval '(emeld-diff "test/example/left" "test/example/right")'
  #+end_src

  or =M-x emeld-diff= and pick the two directories.  Relative paths work
  (they are expanded against =default-directory=).

** What each file demonstrates

  | Path | Demonstrates |
  |------+--------------|
  | =README.md=, =same.txt=, =empty.txt=, =big.txt=, =src/util.el= | identical files (shown with ~S~; exercises the same-file merge) |
  | =modified.txt= | a one-line modification: ~TAB= peek, ~e= ediff, hunk copy |
  | =multi-hunk.txt= | three separate hunks: per-hunk copy, change navigation |
  | =duplicate-blocks.txt= | repeated identical blocks; only the second changed (hunk line-hint targeting) |
  | =no-newline.txt= | no trailing newline on either side (the peek's =\ No newline= marker) |
  | =whitespace.txt= | whitespace-only change (~i~/~w~ filters) |
  | =blanklines.txt= | blank-line-only change (~B~) |
  | =case.txt= | case-only change (~C~; directory mode only) |
  | =comments.c= | comment-only change (~R= with a POSIX regexp, e.g. =^[[:space:]]*//=) |
  | =crlf.txt= | CRLF vs LF (~L=) |
  | =binary.bin=, =docs/images/logo.bin= | binary files (the peek reports "Binary files … differ") |
  | =spaces in name.txt=, =unicode-é.txt= | paths with spaces and non-ASCII names |
  | =symlink.txt= → =same.txt= | symbolic links (=diff= follows the target) |
  | =.gitignore=, =ignored.log=, =build/output.txt= | gitignore handling: simple patterns reach =diff --exclude=, so they hide even outside a work tree; ~I= toggles respect |
  | =backups/app.bak=, =backups/notes~= | the default "Backups" filter group (they differ, but are excluded until the group is toggled) |
  | =src/deep/level1/level2/level3/…= | deep nesting: tree lines, jump-to-file, narrow, depth-limited scans |
  | =many/f01..f40.txt= | many files in one directory; f10/f20/f30/f40 differ (jump, narrow, navigation) |
  | =new-file.txt=, =left-only-dir/=, =to-copy.txt=, =copy-tree/= | left-only ("new") files and directories |
  | =deleted-file.txt=, =right-only-dir/=, =to-delete.txt= | right-only ("deleted") files and directories |
  | =copy-tree/= (40 files) | the chunked built-in copy: mark it and press ~C= without rsync |

  A default scan of the example shows 66 changed files (68 with ~I= off);
  the test suite asserts the full status set, the content-filter effects,
  the peek, and jump/narrow against this fixture.

  Recording notes:

  - Regenerate the fixture before each take (=test/make-example.sh=): the
    mtimes are fixed at 2026-01-02 03:04, so ~f= (file meta) shows the same
    tags every time.
  - For the built-in-copy demo, either run Emacs with =rsync= missing from
    =exec-path= or set =(setq emeld-copy-method 'builtin)=.
  - The git demo repo has four commits, a =demo-branch=, an unstaged edit
    (=main.txt=) and a staged new file (=wip.txt=) — =git diff= does not
    show untracked files, so the new file is staged — giving a
    modification, a deletion and an addition in one comparison.
  - =emeld-ignore-matching-lines= (~R=) takes a POSIX basic regexp, because
    it is handed to =diff= / =git diff= (e.g. =^[[:space:]]*//=, not an
    Emacs =\\s= construct).
